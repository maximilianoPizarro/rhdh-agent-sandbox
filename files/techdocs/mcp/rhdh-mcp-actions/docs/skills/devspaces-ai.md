# DevSpaces AI workspace

## When to use
Coding inside OpenShift DevSpaces (Che Code) with Continue pointed at the sandbox LiteLLM gateway.

## Steps
1. Create/open the workspace from the Devfile in OpenShift DevSpaces.
2. In the browser IDE, open Continue.
3. Point models at the LiteLLM Route (`…/v1`) using `litellm-master-key`.
4. Prefer Hub catalog Resources tagged `skill` and `prompt` for repeatable agent tasks.
