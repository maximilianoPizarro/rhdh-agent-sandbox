# ${{ values.name }}

Node.js / **LangChain.js** agent generated by the Deploy Agent golden path.

## What was generated

- HTTP server + LangGraph `createReactAgent` (or plain chat when `chat-agent`)
- Tools selected from `agentType` (`${{ values.agentType }}`)
- System prompt from `agentSpec`
- LiteLLM via OpenAI-compatible base URL

## Build & run on OpenShift

```bash
oc get bc/${{ values.name }}
oc logs -f bc/${{ values.name }}
oc get deploy/${{ values.name }}
```

## Local (optional)

```bash
npm install
export LITELLM_API_BASE=https://<litellm-route>/v1
export LITELLM_API_KEY=...
export MODEL=${{ values.model }}
npm start
```
