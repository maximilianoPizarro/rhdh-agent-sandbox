# ${{ values.name }}

Python / **LangGraph** agent generated by the Deploy Agent golden path.

## What was generated

- Real `StateGraph` (`parse → llm ⇄ tools → respond`)
- Tools selected from `agentType` (`${{ values.agentType }}`)
- System prompt from `agentSpec`
- LiteLLM via `LITELLM_API_BASE` / `LITELLM_API_KEY`

## Build & run on OpenShift

The scaffolder creates a BuildConfig + ImageStream. The agent-applier starts the binary build and deploys the resulting image.

```bash
oc get bc/${{ values.name }}
oc get is/${{ values.name }}
oc logs -f bc/${{ values.name }}
oc get deploy/${{ values.name }}
```

## Local (optional)

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
export LITELLM_API_BASE=https://<litellm-route>/v1
export LITELLM_API_KEY=...
export MODEL=${{ values.model }}
uvicorn app.main:app --host 0.0.0.0 --port 8080
```
