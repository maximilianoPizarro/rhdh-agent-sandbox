# DevSpaces + Cursor workflow

## When to use
Opening or continuing work in an OpenShift DevSpaces workspace from Cursor.

## Steps
1. Create/open the workspace from the Devfile in OpenShift DevSpaces.
2. In Cursor, connect with Remote SSH to the workspace endpoint.
3. Sync extensions via `devfile` customizations when available.
4. Prefer Hub catalog Resources tagged `skill` and `prompt` for repeatable agent tasks.
