# Agent-friendly Developer Hub (Sandbox)

Helm umbrella chart that deploys **Red Hat Developer Hub** on **OpenShift Developer Sandbox** with:

- **Lightspeed** backed by **LiteLLM** → shared Granite / Qwen models
- **MCP servers** (OpenShift + Kubernetes) for agent tool calling
- **AI catalog** entities for Skills, Prompts, and MCP servers
- **DevSpaces** Devfiles and Software Templates for **Cursor** remote workflows
