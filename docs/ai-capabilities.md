# AI capabilities in this demo

The demo focuses on **capabilities you can install and show today**.

| Capability | How it is delivered |
|---|---|
| Knowledge / multi-model gateway | TechDocs plugins + LiteLLM → Granite/Qwen |
| Saved prompts | Catalog `Resource` entities (`type: prompt`) + prompts pack in GHCR |
| Deep context | Catalog MCP actions + TechDocs MCP + OpenShift MCP live state |
| Skills | Catalog `Resource` entities (`type: skill`) + skills markdown pack |
| AI catalog / agents | MCP server APIs (`type: mcp-server`) + plugin catalog index image |
| Agentic MCP tools | RHDH MCP actions + OpenShift/Kubernetes MCP deployments |
| MCP registry | `files/catalog/mcp-servers.yaml` locations |
| Agent-friendly workspaces | Software Templates + Devfiles for Cursor |
